# Synthetic export fixtures

Files in the shape of the three Siweb UI exports (inventory CSV, movements XLSX, suppliers CSV), generated by
`python -m generator.exports --seed 42 --out packages/testing/fixtures/exports`. Everything here is fictional: SKUs start with
`SYN-`, supplier ids are in the reserved synthetic range, names and addresses are invented. The owner's real exports are never
stored in the repository; they stay in `data/local-exports/` (ignored by version control).
